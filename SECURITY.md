# Security Policy

## Supported versions

| Version | Supported |
| :-- | :-- |
| 1.x | Yes |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's [private vulnerability reporting](https://github.com/Samudra-GITHub/noir-cafe/security/advisories/new) with a description of the issue, steps to reproduce and the potential impact. You can expect an acknowledgement within 72 hours.

## Scope

Noir Café is a static front end. The reservation form, newsletter and shop bag are not yet connected to any backend, and no personal data is stored server-side; the bag and saved recipes live only in the visitor's own browser storage.
